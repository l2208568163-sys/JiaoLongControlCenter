# 蛟龙电竞控制台（移植版）— 使用说明

把机械革命最新的「电竞控制台」（ControlCenterX / CCU.WinUI 5.56.60.34）移植到
蛟龙16 Pro 2023款（主板 MRID6-23，R7 7745HX + RTX 40 系）上运行。

## 本安装包做了什么

安装器（JiaoLongCCU-Setup）会自动完成以下全部步骤，无需手动执行脚本：

1. 部署**桥接服务 JiaoLongCCUBridge**（自包含单文件，目标机无需安装 .NET 运行时），
   注册为 Windows 服务（开机自启 + 崩溃自动重启）；
2. 写入 GamingCenter2 能力开关注册表；
3. 导入 UI 签名证书（TrustedPeople）；
4. 安装 Windows App Runtime 1.7 依赖（已装则跳过）；
5. 安装**机械革命控制中心 UI**（官方 5.56 移植版 MSIX，已移除应用商店入口、注入主页
   Logo 三连击自定义图标与单实例防僵尸补丁）；
6. 创建桌面快捷方式【机械革命控制中心】。

## 启动方式

- 双击桌面【机械革命控制中心】快捷方式，或开始菜单搜索「机械革命控制中心」。
- 桥接服务开机自动运行，无需手动启动。

## 卸载方式

- Windows「设置 → 应用 → 安装的应用」中找到「蛟龙电竞控制台」→ 卸载；
- 或「控制面板 → 程序和功能」→ 卸载。
- 卸载会同时移除 UI（MSIX）、桥接服务与注册表配置，不影响系统其他组件。

## 常见问题

- **启动卡在加载页 60 秒后进入但数据显示 "-"**：检查服务是否在跑
  （管理员 PowerShell：`Get-Service JiaoLongCCUBridge`），重启服务后再开 UI。
- **日志位置**：
  - 桥接服务：`C:\ProgramData\JiaoLongCCUBridge\bridge_YYYYMMDD.log`
  - 官方 UI：`C:\ProgramData\CCU_Gallery\Info\`
- **和旧「第三方蛟龙游戏控制中心」共存**：可以并存，但**不要同时开**——两个都在控制风扇。
- **恢复默认 Logo**：删除注册表值 `HKCU\Software\JiaoLongLogoMod\CustomLogoPath` 后重启应用。
- **安装目录**：`C:\Program Files\JiaoLongCCU`（bridge\ 为服务文件，ui\ 为 MSIX 安装负载）。
